# 🎙 Скрибо — голосовой блокнот с живым переводом

**Говорите — Скрибо напишет.** Диктуйте мысли голосом: текст сам получает знаки препинания и абзацы, а справа сразу появляется перевод на другой язык.

**▶ Попробовать онлайн:** _ссылка появится после включения GitHub Pages_

## Что умеет
- 🎙 Диктовка на ~30 языках: Chrome/Edge, Whisper в браузере или Whisper на компьютере (офлайн)
- ✨ Умная пунктуация и абзацы по смыслу (ключ Gemini или Claude), без ключа — по паузам
- 🌍 Перевод в реальном времени, несколько движков, глоссарий терминов
- 💬 Режим разговора: переводчик «рация» для живого общения
- 📝 Редактор, таблицы с авторасчётом, шаблоны, импорт .docx, экспорт в Word, PDF, Markdown
- 🖥 Интерфейс на русском, українська, English; режимы Минимальный, Стандартный, Широкий; крупный шрифт
- 📲 Работает как приложение на ПК и телефоне (PWA)

## Как запустить
| Способ | Что делать |
|---|---|
| Самый простой | Открыть `index.html` двойным щелчком |
| Windows | `start.bat` |
| Mac | `start.command` |
| Linux | `start.sh` |

Версии для компьютера сами установят Whisper для точного офлайн-распознавания (нужен Python 3.10+).

## ИИ-ключ (по желанию)
⚙ Настройки → «Ключ ИИ»: бесплатный Gemini ([aistudio.google.com/apikey](https://aistudio.google.com/apikey)) или Claude. Ключ хранится только в вашем браузере.
